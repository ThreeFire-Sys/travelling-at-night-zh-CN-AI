# 《夜游漫记》Demo 非官方简体中文补丁

已验证目标：Steam Demo，Windows x64，游戏内构建标识 `2026.8.k.52`。该标识不是 Steam 公布的正式版本号；若游戏再次更新，请留意安装器的版本警告和英文回退。

## 一键安装

1. 完整解压发布包（不要只取其中几个文件）。
2. **双击 `一键安装.bat`**，看到"安装完成"即可。全程无需输入任何命令。

安装器会按 Steam 注册表与库目录清单自动定位游戏（任意盘符、自定义 Steam 库位置均可）。自动定位失败时，才需要手动指定目录（一键入口会把参数原样传给安装脚本）：

```bat
一键安装.bat -GamePath "你的游戏目录"
```

安装前请完全退出游戏。本补丁会把游戏文本资产替换为内嵌中文的版本（被替换的原文件会备份到游戏目录下 `.travelling-cn-backup`），并安装 `TravellingCN` 运行时插件（字体与 F9 切换）；不改动存档。若发现未知 DLL 注入器冲突，安装器会停止并报告。安装逐文件原子替换并持续保存恢复状态；即使中途失败，也可在关闭游戏后卸载回滚。

## 一键卸载

**双击 `一键卸载.bat`** 即可，卸载前请完全退出游戏。

卸载器会先验证全部记录路径，再开始修改；它只移除哈希仍与本补丁一致的文件。单个文件被占用、安装后被用户或其他 Mod 修改、或备份缺失时，该文件会保留并报告，其他安全项仍会继续处理。

## 已知事项

- 游戏更新后，Steam 会把本补丁替换过的资产文件恢复为官方英文版，汉化随之失效。届时请先卸载本补丁，待游戏更新完成后，再安装与新版本对应的新版补丁；安装器提示版本不符时请勿强行安装。
- 首次显示新中文字符时，动态字体可能产生轻微瞬时开销。
- 游戏内按 `F9` 可即时切换简体中文与英文，无需重启。按键和启动语言可在首次运行后生成的 `BepInEx/config/cn.nyctodromy.travelling.zhcn.cfg` 中调整。
- 中文使用 Noto Sans CJK SC Regular 作为原字体的后备字形。默认保持原字号；可在同一配置文件中把 `ChineseFontScale` 调至最高 `1.10`。
- 包内 `术语表与译名说明.md`（另有同内容纯文本版 `术语表与译名说明.txt`）汇总前作固定译名、可核对的中文 Wiki／官方资料链接，以及本作新词的构词与定名理由。
- 这是非官方社区补丁，与 Weather Factory 无隶属关系。现行 Sixth History Community Licence 不包含《Travelling At Night》，不能视为本补丁的分发授权；公开分发前应另行取得 Weather Factory 的书面许可或确认。
