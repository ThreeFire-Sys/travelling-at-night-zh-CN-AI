# 《夜游漫记》简体中文汉化规范

## 总体标尺

目标是“像受过古典教育、经历过战争、又不太愿意把话说明白的英国人写出的清晰中文”。设定文本精确、凝练，可有少量半文半白的秘教语汇；人物对话自然、有身份和时代差异；UI 与机制说明直接、一义。不要把所有文本写成仙侠式古风，也不要把有意的怪异、含混和冷幽默解释掉。

## 文本层级

- 世界观与密传：保留悖论、递归、反复、残句、反问与不确定语气。墙、门、伤口、血、光、皮、骨、火等物质意象尽量直译，不主动替作者解释。
- 人物对话：依据说话人的教育、职业、地域、年龄和当下情绪区分口吻。1940 年代的政治、军政、法人和日常对话用自然现代汉语。
- 主角内心与脚注：允许克制的第一人称感情、调侃、预示和突然的降调；脚注不是中性百科条目。
- UI 与机制：简短、清楚、可操作；同一按钮和机制始终使用同一译名。

## 术语原则

- 大写本体词必须按语境判断，禁止脱离上下文做全局替换。`Hour / Name / Long / Know / Wake / History / Principle / Aspect` 与普通同形词不同。
- `Principle` 是“准则”，`Aspect` 是“性相”，两者不可混用。
- `History / Histories` 依语境译为“历史”“诸史”或“秘史”，不可一律替换。
- 具体实体的代词遵从原文和既有设定；不要把全部神秘存在统一改成“祂”。
- 双关无法兼得时，优先保留设定连线和重复母题；解释写入内部备注，不擅自在玩家文本里加译注。

### 技艺与新术语的构词

- `Skill` 是本作总机制名，项目统一译“技艺”。同作 Steam 商店简介虽使用“技能”，但为延续前作中文的秘教语体，游戏内采用用户确认的“技艺”；这是一项有记录的编辑裁决，不得再由批处理改回“技能”。`Great Arts` 则是秘教知识体系，仍译“伟大之术”。
- 九种 `Great Arts` 必须逐项沿用《司辰之书》现有简中：鸟鸣学、丛林学、司辰学、静默术、照明术、盗火术、夜游术、保存术、蠕虫学。它们恰好都是三个汉字，这是前作既有命名体系，应保持，不得另造四字名或回退为音译。
- `Worldly Skill` 是本作新增的世俗技艺层，译名以简洁自然、准确说明人物能力为先，不设“三个字”硬指标。Steam 官方已经给出“尊严、钻营、修养”；其余名称按同层级构词，不强凑三字。
- 新出现的秘教技艺或与九大伟大之术同级的术语，优先仿照前作构词：核心意象加“术／学”，通常控制为三字；选择“术”还是“学”取决于其偏向实践技法还是知识传统，不能只为凑字。
- 新出现的组织、仪式、器物与人物特质不得套用技艺构词法。先判定概念层级，再参照同层级前作词群定名。
- 任何新术语定稿前至少记录：英文原词、概念类别、同层级前作近邻词、最终译名与排除的候选译名。这样保持的是构词逻辑，而非表面字数。

## 句法与标点

- 书名用《》；卷次用中点，如《夜游漫记·卷一》。
- 中文正文使用中文弯引号、全角标点；省略号用“……”；破折号用“——”。
- 保留原文分号、冒号、排比、重复和短句形成的节奏。
- 保留所有富文本标签、变量、Lua/Sequence 片段、方括号条件与链接标记；只翻译其中玩家可见的自然语言。
- 不把“也许、似乎、恐怕、果真如此吗”一类不确定表达擅自改成确定事实。

## 去除机翻腔

- 翻译句子的作用与节奏，不照搬英语语序。英语长定语链可拆句；中文能省的主语和代词应省，但不能丢失说话人态度。
- 少用空泛支架词：无必要时删去“进行”“能够”“将会”“关于”“对于”“这意味着”“某种程度上”“事实上”。`I find... / I can see...` 也不必一律译成“我发现／我可以看见”。
- 避免把名词硬作动词、被动句硬保留为“被……所……”，也避免连续三层“的”。先问一句中国角色在这个场合会怎么说。
- 不用“其、此、乃、皆、何物”给普通对话强添古意；这些词只在受教育者的书面 lore 或刻意庄严的语境中少量使用。
- 冷幽默常靠一本正经后的突然降调。不要替笑点加解释，也不要把粗口、尴尬、迟疑全部润色成优雅书面语。
- 同一句式反复出现时，先判断它是不是母题。作者有意的重复应保留；模型无意造成的“我想……我认为……我觉得……”则应消除。
- 逐条朗读人物对白。若一句话在演员口中说不顺，或删去英文后无法自然复述，就尚未达到终稿标准。

## 强制 QA

- 检查固定术语漂移与同一专名的异译。
- 检查 `Sister-and-Witch` 与 `Witch-and-Sister` 是否被错误合并。
- 检查人称、性别与“祂/他/她/它”是否与上下文一致。
- 检查富文本标签、双中括号链接、变量、占位符与换行是否完整保留。
- 检查冷幽默是否被庄严化，角色口吻是否被统一成同一种“玄奥腔”。
- 检查标点、书名号、数字、按键名和 UI 长度。
